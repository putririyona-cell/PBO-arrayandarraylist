Bank Management System

#Deskripsi
Bank Management System adalah program sederhana berbasis Java
yang digunakan untuk mengelola data nasabah dan rekening bank.

Proyek ini dibuat untuk mempelajari konsep Pemrograman
Berorientasi Objek (PBO), Array, dan ArrayList.

#Fitur
- Registrasi nasabah baru
- Pembuatan rekening
- Penyimpanan data nasabah menggunakan Array
- Penyimpanan rekening menggunakan ArrayList
- Penambahan saldo (deposit)
- Penarikan saldo
- Pencarian nasabah berdasarkan ID
- Menampilkan data seluruh nasabah

#Cara Menjalankan
1. Pastikan Java JDK sudah terpasang.
2. Simpan semua file Java dalam satu folder.
3. Buka terminal pada folder tersebut.
4. Kompilasi program:

   javac Main.java Bank.java Customer.java Account.java

5. Jalankan program:

   java Main
